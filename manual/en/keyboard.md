# Keyboard Shortcuts

The menu item **Keyboard Shortcuts** shows this list inside the application. <kbd>Ctrl</kbd>+<kbd>?</kbd> opens it. A
header-bar button, its menu item and its row in that window all show the same label.

## Jobs

| Key | What it does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | `New Offload…` |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | `Verify Folder…` |
| <kbd>Ctrl</kbd>+<kbd>L</kbd> | `Seal Media…` |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | `Save Report…` for the selected job |

## Navigation

| Key | What it does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Page Down</kbd> | `Next Job` |
| <kbd>Ctrl</kbd>+<kbd>Page Up</kbd> | `Previous Job` |

With no job selected, the next key selects the first job in the list and the previous key selects the
last. Both stop at the ends of the list.

## General

| Key | What it does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | `Preferences` |
| <kbd>Ctrl</kbd>+<kbd>?</kbd> | `Keyboard Shortcuts` |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | `Close Window` |
| <kbd>Ctrl</kbd>+<kbd>Q</kbd> | `Quit` |
| <kbd>F10</kbd> | `Main Menu` |

<kbd>Ctrl</kbd>+<kbd>W</kbd> and <kbd>Ctrl</kbd>+<kbd>Q</kbd> both ask first when a job is running.

## In a dialog

| Key | What it does |
|---|---|
| <kbd>Enter</kbd> | Press the suggested button: `Review Plan…` in the offload dialog, `Start` on the plan sheet |
| <kbd>Escape</kbd> | Close the dialog. On the plan sheet this throws the plan away. |

`Enter` does nothing while the suggested button is grey.

## Access keys

A dialog underlines one letter of each button. `Alt` and that letter press the button.

| Dialog | Button | Key |
|---|---|---|
| New Offload | `Cancel` | <kbd>Alt</kbd>+<kbd>C</kbd> |
| New Offload | `Review Plan…` | <kbd>Alt</kbd>+<kbd>R</kbd> |
| New Offload | `Choose…` | <kbd>Alt</kbd>+<kbd>O</kbd> |
| New Offload | `Add Destination…` | <kbd>Alt</kbd>+<kbd>A</kbd> |
| Plan | `Back` | <kbd>Alt</kbd>+<kbd>B</kbd> |
| Plan | `Start` | <kbd>Alt</kbd>+<kbd>S</kbd> |
| Stop the running job? | `Keep Running` | <kbd>Alt</kbd>+<kbd>K</kbd> |
| Stop the running job? | `Stop and Close` | <kbd>Alt</kbd>+<kbd>S</kbd> |

## Without a key

**Cancel Job** and **Clear Finished** have no shortcut. Use the button in the detail pane, and the
menu item.
